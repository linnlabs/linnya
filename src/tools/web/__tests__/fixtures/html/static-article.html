本地网页抓取的安全边界

桌面端应用直接抓取网页时，安全边界与服务端代理并不相同。请求从用户设备发出，因此必须在连接前检查目标地址，避免网页地址指向用户本机、家庭路由器或者企业内网服务。

只检查输入字符串还不够。域名可能解析到私网地址，公开地址也可能通过重定向跳到内网。因此每次发起请求以及每次跟随重定向之前，都要重新执行 URL 策略和 DNS 地址校验。

DNS 校验结果还需要绑定到真正的网络连接。如果校验完成后让 HTTP 客户端再次独立解析域名，攻击者可以利用两次解析之间的时间差更换结果。安全实现应当使用已经校验过的 IP 建立连接，同时保留原域名作为 Host 和 TLS SNI。

抓取层还必须执行总超时、响应体上限和取消合同。压缩响应应按解压后的字节数计算预算，避免很小的压缩包在内存中展开为超大正文。上述规则共同构成可测试、可观察的本地读取基础。
