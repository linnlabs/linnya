# 按读者、材料和证据选择写法

这是写作资料包，不是统一提纲。报道、投研、预测等是交付目的和证据合同；同一财经题可以写成报告、解释长文或评论。先保留用户的用途、读者、篇幅和参照要求，再选合适的主线与语气。

## 什么时候选，怎样选

在调查已足以支持成文之后、完整初稿之前选；固定材料编辑先读正文与相关依据再选。不要在尚未了解材料时锁定结构。后续发现材料不足或核心解释改变，可以调整写法。

先判断读者需要带走什么：可查找的评估、对现象的理解、一个有论据的判断、作品的理解，还是研究领域的证据地图。再看手头材料：有无可靠的具体经历和行动、可比较的材料、可支持的机制、不能消除的价值取舍。选择能承载这些材料的主线，不因为题目有个人物/建筑就写故事，也不因为有数字就写报告。

先读下面目录，再实际读取最合适的一张卡；确需组合时才补读第二张。卡中的走法是选择，不是互斥门类或必填章节，不必全读或照着卡片小标题成文。

| 卡片 | 适合的读者任务与材料 | 容易误选的情形 |
| --- | --- | --- |
| [报告 / 简报](genres/report.md) | 集中获取描述、评估、条件判断或行动依据；需要摘要、导航、表格或分项查阅 | 只是材料多便套报告；把所有研究都改成行动建议 |
| [解释性长文](genres/explainer.md) | 理解现象怎么发生；有可说明的机制、比较或竞争解释 | 强行将几个相容解释排成已确定的主因 |
| [分析与评论](genres/analysis.md) | 比较方案、判断或价值取舍；有可比较材料与清楚论据，有实质异议时回应 | 只有态度却没有理由；把价值偏好写成事实答案 |
| [作品批评 / 阐释](genres/criticism.md) | 理解具体作品或文本，能细读可定位的形式、细节和语境 | 只读简介就评价全作；把作品变成作者生平的附注 |
| [研究综述](genres/synthesis.md) | 理清研究怎样回答同一问题、何处分歧及为何分歧；有可比较研究 | 将检索到的若干文章按作者逐篇介绍，冒称穷尽 |
| [叙事特写](genres/narrative.md) | 人物、物件、地方或事件的具体材料能揭示问题；有可核行动、记录或细节 | 没有现场就补造现场；为了首尾呼应编情绪或结局 |

“困境→可行选择”“材料→概念区分”“机会地图→执行条件”可作为某张卡内的主线，不另加一套必须执行的流程。也允许报告中的解释段、评论中的可靠叙事，组合仍须服务同一篇文章。

## 留下简短写作方向

在已有研究记录中留三行即可，不新建表格或工具：

1. 读者与用途；
2. 主要写法、语言语气及为什么适合手头材料；
3. 大致推进关系和希望读者记住的一点。

这是作者当时的选择，不是质量证明。交互中按需要向用户说明方向；用户要求先确认才等待，否则继续。Benchmark已约定自主成文时不额外等待批准。不要照搬Slides的逐页计划、theme或审批合同。

## 通用手艺

- 先判断读者理解开篇判断需要知道什么。第一次让普通读者接受“大、小、恢复、异常、成功”等判断时，先给足对象是什么、为何值得关心及相对什么而言的必要语境；不能等到后面的机制章节才补这个入口。可从新闻、历史、日常疑问、具体事物或平实现状进入，按材料选用；不固定年代开场，也不一次铺完百科背景。更深的历史、方法与异文在有作用时展开。
- 下一段应在内容上承接：回答未解问题、增加证据或条件、改变比较尺度，或让人物行动带出制度。明确的路标句、小标题、摘要都可以帮助读者；它们要确实指出接下来的关系。
- 删并换词重讲却没有新作用的段落。回扣可以改变理解、评价或情感意义；摘要与正文的不同入口也合法，不按重复词机械去重。
- 细节和数字要承担理解、比较或判断的作用。材料的重要性决定篇幅，不平均铺开所有因素；术语、句长、第一人称有无都不是质量分数。
- 问题已从材料的矛盾或差异中显现，就顺势推进，不再复述“本文要回答什么”。解释和分析通常让材料、推导与结论呈现立场，省去无必要的“我认为、我建议、我的立场、本文将”；保留人物、机构、动作与责任等必要主体。亲历、随笔、作品阅读经历或用户指定的第一人称文体可以保留作者位置，允许不等于默认使用。
- 场景、引语与事实只用可核材料；价值尺度说明白，不冒充采访、亲历或人物内心。生动与严肃都不能把证据强度提高。

## 怎样使用示范

每张卡的示范只展示一次具体安排，不是默认开头、结尾或可引用来源。照搬其句型、反转或首尾物件会让不同文章一个模样。按本题材料决定怎么进入、怎样结束；没有反常现象可以平实说明，没有适合回扣的对象可以直接收束判断。

通常不必上网找文风。用户指定某份格式、规范或参照文时，先实际检查所给材料或权威要求；提取结构、语言和读者预期，不抄句子，不默认模仿名家声口。
