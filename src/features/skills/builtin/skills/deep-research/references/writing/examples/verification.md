# 两处示范的核实说明

这些入口只说明教学示范的依据，不是其他研究主题的来源，也不是作者必须模仿的句型。卡片中的虚构平台、社区食堂及给定文学文本均明确虚构，不作为现实事实。

## 冬季湿度

依[FAO气象数据说明](https://www.fao.org/4/X0490E/x0490e07.htm)的饱和水汽压与相对湿度公式，零度的饱和水汽压约0.611 kPa，二十度约2.338 kPa。在水汽/干空气混合比不变、总压近似不变的条件下，水汽压近似不变，80%变为约20.9%。

“不增加水汽”本身不足以唯一确定结果，密闭定容加热时水汽分压会随绝对温度变化，约为22.4%。这不是对实际房间最终湿度的预测；水源、混合与通风都可能改变结果。

相对湿度高不等于水汽多。“不是外面空气干，而是加热”混合了不同含义，应改成给定条件下的具体解释，不用二分口号收束。气压与水汽混合比的定义另见[美国气象学会](https://glossary.ametsoc.org/wiki/mixing-ratio/)。

## Ideal X

[纽约新泽西港务局的历史回顾](https://portfolio.panynj.gov/2016/04/27/port-newarkmalcom-mcleans-box-changes-the-world/)支持1956年4月26日、纽瓦克至休斯敦、58箱。[美国国家历史博物馆](https://americanhistory.si.edu/explore/exhibitions/america-on-the-move/online/transforming-waterfront)解释此前尝试、机械化联运、配套设施和兼容要求。

卡片不声称这次航行首创所有箱运思想、不补写全部货物在工厂装入，也不说箱体从未被搬动。应区分货物逐件倒装与箱体整体接运。

国际标准帮助兼容和扩大网络，不能写成标准出现前未能整箱运输。[ISO历史](https://www.iso.org/about)记载首个货箱标准于1968年发布；尺寸、角件与作业又有各自演进，不是一项标准一次完成全部协调。示范只提出值得继续解释的关系，完整史论仍须本题实际取证。
