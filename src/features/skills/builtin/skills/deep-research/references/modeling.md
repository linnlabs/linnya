# 立场、线索与解释建模

选模型是为了回答问题，不能为了展示贝叶斯、因果图或矩阵而制造额外任务。

## 从什么未知开始

先区分描述、解释与预测。描述问发生了什么；解释问哪些机制与观察相容；预测问定义清楚的未来事件。它们都可使用假设，但不都需要数值概率。决策另需目标、选项与损益；在没有这些输入时，先交付研究结论。

对关键争议提出具有不同可观察后果的解释，而不是列同义假设。保留基准解释，并问什么资料能区分它们。例如需求增长与重复申报都可能造成申请数增加；项目实际投产比另一篇转述申请数的文章更有区分力。示例说明方法，不预设任何真实研究的答案。

区分性取决于两种解释的预测差异，不取决于有多少指标同向。价格或政策调整后的成交/使用量可能在需求减弱时仍上升；新增流量下降也不代表既有存量消失。先定义观测量、比较基准和时间窗口，再检查另一解释是否也能产生该观察；不能从两个相容机制直接判主次，也不把温和的替代解释改成崩塌等极端版本。必要时寻找可比对象、未受影响组、时间顺序或直接约束；若取得不了，保留无法识别的范围。这些是识别风险的例子，不是每题的固定检查表。

每个重要判断至少能说清：依据是什么、连接依据与结论的前提是什么、哪个替代解释尚未排除、什么观察会改变判断。可以用短段落表达；不要求固定数量或强制结构化表。

## 先审视材料，再解释事件

材料本身也是研究对象。对关键或有争议的材料，检查以下几件事；与本题无关的作者背景无需展开：

- **位置与信息来源**：谁写、谁发布、引述谁，信息是亲历、原始记录、转述还是推测？各自能知道什么、有哪些信息盲区？
- **立场与受众**：它明确主张什么，希望谁改变哪种认识？区分事实判断、价值偏好和行动倡议，不从措辞直接猜测未披露身份或动机。
- **利益与约束**：核对与本题有关的公开资助、所有权、商业或制度关系；它们可能影响材料的选择，但不能代替逐条事实核查。必要时离开原文查独立资料，不只相信来源的自我介绍。
- **叙述选择**：标题是否比正文更强，数字为何选这个分母、年份和比较对象，引用了谁、缺少什么相关视角？回到原始表格、完整引语和不同立场的一手材料，检验这些选择是否改变结论。

“未被这篇文章呈现的事实”“当前未知”“作者故意隐瞒”是不同判断。前两种可以通过补查说明，第三种还需要意图证据。不要给媒体整体贴可信/不可信标签后停止核查；对立来源也可能重复同一个错误，有利益关系的来源也可能提供正确且独有的记录。证据强弱不对称时无需人为各打五十大板。

事件参与者另看：谁得到收入、地位、政策空间或风险转移，谁付出代价；决策权、执行能力和代价是否落在同一方；短期激励是否与长期目标冲突。把公开说法、已观察行为、可核实约束和推测动机分开。收益、价值观、职责、误判、惯性与协调失败都可能解释行为，不能默认“获益者就是推动者”。

## 从零散现象找到可核查的联系

先列出最值得解释的异常：说法与行为不符、不同指标背离、多个地方出现相似变化，或原有解释无法覆盖的个案。回查时间、定义和报道来源，确认异常不是不同口径、披露时滞或同稿转载造成的。

对重要异常提出少量有不同可观察后果的解释。可以假设多个现象是同一机制的表现，但必须写出共同原因如何分别影响它们；也允许多个原因共同作用。保留合理的基准解释，不为了“有洞见”强行推翻常识。

将解释转成下一次查找资料的具体任务：

| 从哪里扩展 | 要查什么 | 先说明的连接理由 |
| --- | --- | --- |
| 参与者及关系 | 相关公司、客户、供应商、出资方、监管者的原始记录 | 哪种合同、依赖或激励可能传导影响；同名或同一投资者本身不证明协同 |
| 事件前后 | 决策、签约、执行、交付与结果的时间线 | 原因是否先于结果，是否存在合理滞后或更早的共同冲击 |
| 资金与实物流 | 收付款、库存、价格、产能、交付、使用量等相关记录 | 哪个可观察量应随候选机制变化，如何避免口径混用 |
| 制度与外部条件 | 规则变更、融资条件、资源约束及相邻地区或行业 | 看似题外的条件怎样改变行为，哪些相似对象可作对照 |

检索词由“主体/变量 + 预期行为或记录类型 + 时间/地区”构成，不必含原题措辞。优先查一个能区分解释的关键环节，读到新资料再调整，不一次穷举整张关系网。超出允许材料或预算时记录缺口，不擅自扩大范围。

例如在一个假想的行业研究中，出货增加、折扣扩大、应收账款上升可能提示终端需求与渠道发货不同步，也可能来自季节性、产品组合或账期改变。下一步可查渠道库存、终端登记、合同账期和现金回款，并对齐时间范围；继续搜“行业需求旺盛”很难区分这些解释。这个例子只说明如何生成查找方向，不预设真实行业结论。

检验连接时问：若解释成立，还应看到什么；若不成立，眼前线索是否也很常见？查找独立记录、反例和可比对象，避免把共享一个数据源的多条线索重复计权。不把时间接近、共同利益或相关性单独当因果。只有在某现象本来应发生、应能被当前方法观察到，而且资料足够完整时，缺失才可能成为反证。

重要推断在研究记录中简述“观察 → 候选连接 → 核查结果 → 尚缺环节”，保留被排除的主要解释和原因，避免只展示最终故事。来源支持观察，不一定直接支持我们的新解释；正文应明确这是推断，给出必要前提和仍未排除的解释。间接证据可以形成判断，但不能把尚缺的中间环节写成已发现事实。

## 检查研究者自己的偏向

阶段性问自己：是否只是沿用户或最初报道的措辞找支持？最关键的证据若撤掉，结论还成立吗？现在的解释提出了什么新预测，还是能事后解释任何结果？哪些相反材料被过早忽略？发现问题就调整解释和搜索方向，不只补一段形式化反方。新资料不再区分解释、相关记录不可取得或预算耗尽时，停止扩展并交付有边界的结论。

## 方法选择

- **因果分析**：区分相关、时序与识别依据；考虑选择偏差、共同原因、反向因果及机制缺环。不能从两个真实事实之间添加“因此”就推出因果。
- **定量模型**：先核对输入单位、口径、适用期间与依赖，实际执行公式。将输入、推导、情景假定、结果分开；特别检查分母是否回答本题，以及“上限”是否由资料或约束推出，而不是作者随口命名。历史情景的可替代量不等于未来技术上限，较低供能占比也不自动代表较低可靠性贡献。更新输入后重算，并回查最终正文的比较与判断。
- **情景/敏感性**：围绕足以改变结论的少数驱动量设条件范围；说明范围来自数据还是探索假定。检查不同情景内部是否一致，不为每个变量随意配悲观/中性/乐观三档。
- **贝叶斯更新**：只有问题和证据结构适用时才做。交代先验来源、似然依据与证据间相关性，避免将共同来源重复相乘；执行后验及敏感性计算。似然缺失时给条件分析或定性更新，不能用模型自报小数冒充客观概率。
- **可结算预测**：写清事件、日期、范围和核实来源；概率若给出，说明依据。到期前不能报告准确率或校准；少量未结算预测不能证明预测能力。不要承诺不存在的自动监测。

## 新证据到来时

定位它改变的是事实输入、来源版本、前提还是表达方式；沿依赖检查相关判断，保留未受影响的结论。反证可能削弱或缩小原判断，不一定要求完全翻转；维持或修订都应给出理由。真实冲突可以保持未解，不能用流畅措辞消除。

下一步查找资料的优先级取决于它是否可能区分解释、改变结论，以及取得成本。不把“继续搜索”当自动下一步；需要尚未进行的访谈、实验或现场观察时，明确提出具体信息缺口，不能伪装成已经完成。
