# 图片：取得、插入与说明

照片、作品图、地图或示意图承担具体的解释任务：让人看到正文正在讨论的对象、空间关系或细节。选图时先说明它能帮助理解哪一点，再核对来源页的对象、时间、图注和署名；按来源的使用条件保留出处。统计比较继续使用 [图表资源](charts.md)。

图片语法和来源路径以内置 Skill `linnya-markdown` 的 `references/image.md` 为准：激活该 Skill，再用 `read_resource` 读取。研究资源只说明取证与成文步骤，语法维护在同一个入口。

1. **取得并看图。** 将选定的图片实际保存到当前会话工作目录，用 `read_file` 读取图片内容，再核对它与来源说明是否相符。文件名、下载成功或图片清单只说明取得状态；无法取得或查看时说明限制，保留可核的文字。
2. **插入并解释。** 按语法资源将图片放入正文独立段落，图注指出对象和值得看的细节，紧邻正文保留来源引用、必要署名与时间。裁切、标注、合成或自制示意要说明其性质；示意用来解释结构，实景或观测结论仍由来源材料支持。
3. **保留到终稿。** 同一文档编辑沿用回读得到的图片身份。另存修订稿时，从本会话保留的原图片文件重新插入，使用语法资源规定的来源路径；图片身份只属于原文档。最终回读确认图片、图注、位置和来源一起保留。文字回读核身份和结构，实际像素读取才核画面。
