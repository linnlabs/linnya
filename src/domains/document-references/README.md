# 稳定文档引用

本 domain 拥有文档间的引用关系与反向索引。目标以稳定 document ID 保存；标题、路径、插件可用状态是查询时派生事实，不复制进关系表。图片字节、Editor 节点和插件改动组不属于这里。

`createDocumentReferenceOperations` 接收调用方连接和 Workspace 节点读取 port。`replace` 必须在已有同步事务中调用，不自行提交或广播；源正文和索引因此一起成功或回滚。插件通过 `@plugin/backend/documentReferences` 消费，不访问 Core 表。

新建引用要求活动源、活动目标和相同项目。已有引用随文档移动仍保持原目标；跨项目时返回 outside_project，移回后恢复。目标删除后返回 deleted，同名新文档不会接管旧身份。反向列表只展示与目标当前同项目的活动来源；目标或来源已软删除时不展示，插件停用不移除关系。目标没有外键级联，保证删除后仍可解释原引用；源物理删除级联清理其关系。

可信Markdown读取基线属于活动reader（对话＋run），不能用全局1024条FIFO挤掉其他读者或同画布的早期卡片。每个数据库/插件实例持有独立基线；Host在root和child的成功、失败、取消、替换终态释放对应reader，暂停/等待用户继续持有。插件停用dispose释放其所有读取记录并退出Host索引。内存随活动读取线性增长，不能通过静默淘汰把已读事实说成未读。

引用replace在整批准入后只增删真正变化的关系；未变稳定身份不写库，新目标按ID在同一事务内复用读取。

业务测试覆盖事务回滚、改名/转移/删除/恢复、同名替换、越界新建和软删除来源。宿主 schema provider 在 Workspace 节点表之后注册，不依赖任何插件已安装。
