# Markdown 图片事实

该 feature 拥有图片出现位置、文档内引用、来源快照和资产可达性规则。`@app/schemas` 提供前后端共同准入合同；这里从正文和 Pending 提取来源、物化引用并禁止未接纳来源或重复图片节点身份落库。

图片出现 ID、rootBlock ID 和 asset ID 各有独立生命周期。修改同一位置的题注保留出现身份，复制分配新身份并复用资产。Pending 自持完整图片快照，不能依赖原图节点仍存在。块历史与正文历史中的引用仍属可恢复内容。

跨领域只通过 `MarkdownImageOwnershipPort`：Host 按数据库绑定，Markdown 在持久化事务内交付保留集。无端口时不得保存带受管资产的新内容；普通文字文档不扫描全部历史。资产取得、目录权限、字节读取和回收均由 Host/Asset 所有者负责。
