# Support

Linnya is maintained by an individual developer and does not provide a guaranteed support SLA.

Use [GitHub Issues](https://github.com/linnlabs/linnya/issues) for:

- reproducible bugs in the public source or current public build;
- focused feature proposals;
- public documentation corrections;
- questions that can be answered without credentials, personal data, or private infrastructure details.

Before opening an issue, search for duplicates and include your operating system, Linnya version or commit, reproduction steps, expected behavior, actual behavior, and relevant sanitized logs. Do not post API keys, database contents, private documents, or full user directories.

Security vulnerabilities follow [SECURITY.md](SECURITY.md), not a public support issue.
