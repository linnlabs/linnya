# Renderer启动热更新

App根组件装配页面级Host port与registry，不能在旧单例尚存活时重新执行setup。开发服务器在Vue处理完本次文件变更后，沿真实模块导入图检查传播边界：将到达App根组件的JS更新改为整页重载，并停止发送这批模块更新。普通Vue子组件、显式依赖接纳与CSS仍使用自己的HMR边界。

只在`builtin/index.ts`接纳更新不能覆盖App直接导入Editor公开合同等另一条路径，因此边界放在开发服务器，先于任何旧页面模块重执行。它不进入生产构建，不清理测试port、不绕过重复注册保护，也不保留旧adapter。修改启动装配依赖前应先保存草稿。
