@napi-rs/canvas 1.0.8 native component notice

Scope
-----

Linnya uses the prebuilt native package selected by @napi-rs/canvas@1.0.8.
The platform packages contain a statically linked Skia-based Node addon, so
their package-level MIT declaration is not the complete component inventory.
This notice records the reviewed source and license boundary for that binary.
