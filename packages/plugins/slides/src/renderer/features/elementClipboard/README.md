# Slides 同稿对象剪贴板

复制通过只读 copy-objects IPC 读取精确修订的完整作者值，不读取画布排版行。store 仅持有 documentId 与对象值，切文稿清空；粘贴/重复生成新 editKey，以 0.2 英寸偏移调用普通 insert_objects；每次粘贴后剪贴板记住新位置，连续粘贴依次错开。重复直接读取当前选区并粘贴，不覆盖剪贴板。呈现后在用户选区未变时选中副本。内容包含富文本 runs；图片只复用本稿拥有的资产 ID。

当前仅支持顶层有宽度约束的纯文字、纯色矩形/椭圆和编辑器插入的普通图片；复杂 Frame、非纯色/描边/阴影/旋转等形状、图表、公式等应复制整页。能否复制由编译器投影的 `copy` 能力决定，与后台复制共用 `readCopyableAuthoringValue`；任一选中对象没有该能力时复制与重复按钮直接禁用，不再提交注定失败的请求。没有系统剪贴板、跨文稿资产复制、网页 HTML 解释等隐含行为。

Cmd/Ctrl+C/V/D 在画布或普通命令按钮拥有焦点时触发，输入框使用自身行为。失败原因写入可关闭的普通提示，不进入保存屏障。复制先交接文字并等待保存，然后以已提交 revision 读取；画面刷新可晚于保存。粘贴与页面重排共享页序互斥。规则与状态均留在此 feature，command bar 通过公开入口组合。
