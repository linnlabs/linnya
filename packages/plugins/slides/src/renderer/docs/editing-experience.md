# Slides 网页编辑体验

Slides 面向生成文稿的日常编辑和简单空白创作。`deck.js` 是唯一可写文档真源；画布、属性和历史都是同一源码修订的投影。编辑模式仅在 ready 的生成文稿中可用，空白页也可以进入。

## 日常操作

| 操作 | 行为 |
| --- | --- |
| 单击、双击 | 单击选择作者对象；双击文字进入输入。Frame 首次选择外层，再次点击进入子层 |
| 取消选择 | 点击幻灯片背景或周围舞台留白；属性控件和滚动条保留自身操作 |
| 多选 | Shift 点击切换成员（同一 Frame 内的子对象保持在子层）；空白拖动框选，Shift 框选追加；Ctrl/Cmd+A 选当前页 |
| 移动 | 拖动、方向键 1px，Shift+方向键 10px；单位为幻灯片 CSS px，与缩放无关 |
| 吸附 | 页边/中心和其他对象的边/中心；屏幕阈值 6px，Alt 临时关闭，Shift 锁主轴 |
| Escape | 先取消当前手势或未提交文字，再取消选区；不撤销已经保存的修改 |
| 删除 | Delete/Backspace 或对象工具条；多选是一个原子动作 |
| 对齐/分布 | 单选对齐页面，多选对齐选区外框；三个及以上对象可按可见边界等距分布 |
| 文本 | 字号、颜色、粗体/斜体/下划线、整框对齐；非空文字选区只改变局部样式 |
| 文本宽度 | 命令栏数值输入，单位英寸；保留原有高度和溢出策略 |
| 插入 | 文字、矩形、圆形、PNG/JPEG/WebP 图片；在当前页中央放置并进入普通作者节点链路 |
| 图片 | 本地文件不超过 20MB；替换保留外框；支持完整显示和居中裁剪填满 |
| 复制 | Ctrl/Cmd+C/V、Ctrl/Cmd+D 或按钮；同文稿会话剪贴板，新对象获得新身份；不支持的对象直接禁用复制 |
| 图层 | 单个对象置顶/置底、上移/下移一层；只改变作者兄弟的绘制顺序 |
| 页面 | 新建、复制、删除；缩略图拖动重排或菜单前移/后移；至少保留一页 |
| 撤销/重做 | Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 或 Ctrl+Y；当前后台会话最多 50 个编辑步骤；完成后跳到受影响的页并重新选中对象 |

输入框、文字编辑器、菜单和 IME 拥有自己的键盘事件。点击命令栏和对象工具条的普通按钮不夺走画布焦点；焦点停在按钮上时 Ctrl/Cmd 文稿快捷键仍然生效。文字输入中 Ctrl/Cmd+Z 使用原生编辑历史；退出输入后使用文稿撤销。Ctrl/Cmd+Enter 提交文字，普通 Enter 换行。

一次拖动、一次长按微移或一次批量操作只有一个撤销步骤。仍在排队、尚未提交的同一对象同一属性修改（例如连点字号、连续调色、宽度、尺寸、方向键平移）合并为一次写入和一个撤销步骤；改不同属性仍是各自的撤销步骤，避免快速连点时逐次排队编译；文字会话、删除、图层、插入和页面动作始终各自独立。后台保存时仍可选择和编辑其他对象。页索引相关动作和历史恢复呈现前暂不接纳另一项页索引操作，防止使用过时页序。

## 保存与恢复

状态依次区分正在编辑、正在保存、已保存正在刷新、已保存及失败。不支持复制、图片过大等未发生写入的提示是可关闭的普通提示，不进入保存屏障，也不禁用撤销。保存成功由后台 revision 决定，画面刷新失败不能谎报写入失败；恢复刷新不会重复写源码。失败文字保留为本地草稿供继续编辑，未确认的 IME 不会被强行提交。正常关闭走保存屏障；进程异常退出不保证尚未交接的输入草稿。

撤销创建新的源码修订，并恢复该修订拥有的主题和资源；历史压缩保留全部有效撤销/重做依赖。新编辑清空重做。AI、直接源码编辑或历史面板恢复属于外部修订，会重置会话撤销栈；插件重启也会重置。持久源码历史仍可通过 Core 历史面板使用。

## 当前明确边界

- 对象复制支持顶层有宽度约束的纯文字、纯色矩形/椭圆（保留文字 runs）以及通过编辑器插入的普通图片。复杂 Frame、图表、表格、公式、SVG、带复杂视觉效果的对象明确拒绝独立复制，可复制整页；不通过压平丢失作者结构。
- 剪贴板为同文稿会话范围，不承诺系统剪贴板、跨文稿粘贴或从网页粘贴 HTML。选择多个对象时任何一个不支持，整次复制失败。
- 页面结构操作要求可证明的静态 compose 列表和明确作者身份。动态生成页面继续使用源码/AI；删除被其他页面引用的局部变量可能编译失败，失败不会提交半份文稿。
- Text 宽度编辑不等于自动增高；沿用作者已有高度与溢出处理。Shape 富文本可保真复制，但原位输入仍限纯字符串。公式行、表格单元格、图表数据、自由裁剪焦点、组合/解组、锁定、旋转手柄和演示动画不在此基础编辑面。
- 同稿粘贴目前固定偏移 0.2 英寸；不会自动寻找无重叠位置。图层次序保持原父级和 Flex 位置，不改变布局树。

## Owner 与性能

| Owner | 职责 |
| --- | --- |

| [manualEditing](../features/manualEditing/README.md) | 作者目标和乐观投影、串行队列、精确修订、回执 |
| [editingCommands](../features/editingCommands/README.md) | 对齐/分布、历史命令、图层、保存状态 |

| [imageEditing](../features/imageEditing/README.md) | 图片接管、替换与 fit |
| [elementClipboard](../features/elementClipboard/README.md) | 同稿会话复制、粘贴与重复 |
| [stageZoom](../features/stageZoom/README.md) | 视口测量、缩放、滚动和绘制坐标 |
| [后台人工编辑](../../backend/features/presentationManualEditing/README.md) | 严格命令、源码写回、原子提交和 Undo/Redo |

拖动/长按期间只更新本地预览，结束后编译一次；PPTX 在导出时按修订延迟物化。文本编辑器延续异步加载，未增加编辑框架依赖。历史 diff 搜索有 10ms 预算，以少量存储换取响应速度；定期 checkpoint 直接保存全文。画布平移落在编译器 1e-4 英寸格点上，单个顶层对象的平移直接投影到已编译快照；文稿含新增对象时按新源码同步这些对象的源码定位，不退回整稿编译。

`smoke:preview-transitions` 使用真实 Electron 输入和生产 Stage/队列，覆盖交互、富文本、IME、完整帧及增量缩略图。后台 `manual-edit-history.integration.test.ts` 使用真实编译和 SQLite，覆盖源码/修订/历史压缩/图片依赖。两者分别替换 IPC 与 Host 资产字节端口；不能当作已安装 Desktop 中真实用户文稿或 Microsoft Office 的验收。性能统计须注明样本、冷/热运行与计时范围。
