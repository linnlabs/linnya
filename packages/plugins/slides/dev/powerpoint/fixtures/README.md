# 图像回归样本

`office-*` 是固定合成样稿的 Slides 预览与 macOS PowerPoint 16.110.2 PDF 导出 PNG 的无损裁片。
不包含用户资料、字体文件、PPTX、PDF 或完整运行目录；单张最大约 23 KiB。测试运行只读这些固定 PNG，
不需要 PowerPoint、Electron、系统字体或外部产物目录。

文件后缀 `-preview` / `-office` 表示两端；裁片保留原始像素尺寸，不缩放。以下坐标基于 960×540 原图，
测试中的 region 坐标相应减去裁剪原点：

| 文件前缀 | 原页 | 裁剪 x,y,w,h | 用途 |
| --- | --- | --- | --- |
| office-boundary | 1 | 78,30,329,260 | 保留真实整体位置差异、溢出和重叠墨迹的不可判定状态 |
| office-shrink | 2 | 96,96,269,70 | 三条紧排文字之间的空白像素行 |
| office-vertical | 3 | 230,96,100,330 | 两个正文列与离散标点 |
| office-spacing | 4 | 96,96,672,192 | multiple 的 45px/54px 步进差异 |
| office-gap50 | 5 | 48,48,864,432 | 排除图例、测量纯色绘图区、保留图例差异 |
| office-gap300 | 6 | 48,48,864,432 | 重叠柱的可见部分、图例与轴刻度抗锯齿 |

其余 PNG 是固定几何墨迹图：矩形模拟文字，专色矩形/折线/扇区模拟图表，不含字体。
`chart-top` / `chart-right` 检查图例方向；`chart-line` / `chart-doughnut` 及 `-drift` 检查系列几何，
避免把非柱图强行解释成柱宽。它们只测试图像比较逻辑，不代表新样稿已经完成真实 Office 验收。
