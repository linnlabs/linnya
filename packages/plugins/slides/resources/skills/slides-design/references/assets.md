# 素材：要什么、去哪找、怎么记许可

计划时先定每页靠什么说话（见 [`design.md`](./design.md#视觉材料)），再按本文找素材。本文教的是找法，表里的来源都是示例：没列到的来源，只要许可允许当前用途，同样可以用。

## 按题材要什么

| 题材 | 主要素材 | 注意 |
|---|---|---|
| 品牌、发布、营销 | 产品图、场景图、去背主体、质感背景、装饰字 | 先用用户提供的素材；不编造 logo、评价和数据 |
| 文化、历史、博物 | 文物和书画实物、拓片、古籍书影、纹样、书法字 | 逐件署名；书法字体见 [`style-cultural-imagery.md`](./style-cultural-imagery.md) |
| 科学、技术、课件 | 准确的图解、实验和显微照片、数据图 | 准确第一；图解用原生形状或 Path 画 |
| 投研、咨询、汇报 | 图表、少量现场或产品照片 | 拿数据自己画，数字写清来源，不截别人的图表 |
| 知识卡片、方法论 | 简单图标、示意图、大数字 | 一份稿只用一种线宽和风格；图标画能看出来的东西，例如灯泡，而不是“创意” |
| 纪实、自然、公益 | 纪实照片、档案图、地图 | 不用来路不明的图 |
| 政企、行业方案 | 行业场景照片、设备图、示意图 | 具体设备用厂商的图，示意场景可以生成 |

## 去哪找：先想原件在谁手里

行业和题材数不完，不要背渠道表。先想这张图的原件在谁手里，再用原件方所在地的语言去搜它：中国的文物和企业先搜中文站，日本的先搜日文站。下表是示例，不是清单：

| 要什么图 | 原件在谁手里 | 注意 |
|---|---|---|
| 文物、书画、古籍 | 收藏它的馆 | 先查这件东西藏在哪，再去那家馆的官网或数字文物库找；海外馆见 [`style-cultural-imagery.md`](./style-cultural-imagery.md#素材) |
| 具体产品与设备 | 厂商的新闻中心或媒体资料包 | 一般允许介绍性使用、要注明来源；不暗示厂商背书；分清实拍和渲染图 |
| 设施与工程 | 运营方、行业协会、政府部门 | 美国联邦机构的图多为公有领域，个别图库另有署名格式 |
| 自然现象、天气、卫星图 | 科研与气象机构 | NASA、NOAA 多为公有领域，其他机构逐家看条款 |
| 统计、行情、经贸 | 不用图 | 拿数据自己画图表 |
| 人物 | 本人、所属机构或用户 | 有肖像权，只用官方发布或用户提供的 |
| 中国地图 | 标准地图服务 | 原样使用并保留审图号，不自绘 |
| 抽象概念、装饰、虚构场景、未来设想 | 没有原件 | 可以生成，见下文“生成图” |

工具：

- **`image_search`**：查开放图库（Wikimedia Commons、Openverse），每张带回尺寸、许可和署名。用 1–3 个关键词，中英文都试。热门题目在开放图库里往往只有那几张，所以挑图前也去原件方那里看一眼。
- **原件方的网站**：用 `web_search` 以原件方的语言搜，例如“馆名 + 器名”“厂商 + 型号 + 新闻图片”。再用 `web_read` 读藏品页或新闻页，结果会列出页面上的大图、图注、署名和页面版权声明。
- **下载和看图**：图片地址交给 `web_read` 下载，回执里带着当时记下的来源；模型能看图时，用 `read_file` 读下载的文件，逐张看清楚再选。
- 也可以在 Shell 里直接调用公开的接口（例如 NASA Image Library `https://images-api.nasa.gov/search?q=<词>&media_type=image`）。下载到 `assets/` 再引用，见 SKILL.md 的资产路径说明。

### 纹样和装饰

纹样和装饰取自这个题材自己的材料，即同一题材的实物、拓片、建筑构件、产品结构或现场照片上本来就有的图形。找到原图后，或者直接取局部（`crop`），或者照着它的结构用 Path 画成矢量，并在备注里写明照哪件东西画的。不要套和题材无关的通用装饰。没有现成的纹样库，每份稿子都按自己的题材现找。

### 生成图

- **可以生成**：装饰和质感、概念插画、虚构或未来的场景、不指认具体对象的示意场景（“一座储能电站”）、封面氛围图。小元素可以一次生成一张纯色底的宫格图，再用 Shell 抠掉底色、切成透明小图，比逐张生成省。
- **不可以**：冒充具体的真实对象（这件鼎、这款车、这座电站、这个人），也不用于数据图、科学图和纪实内容。找不到真实的图，就换讲法或请用户提供。
- **标注**：生成图在备注或末页注明“AI 生成”；用 Shell 处理生成图时不要剥离图片里的元数据。

## 许可：按用途分三档

| 档 | 是什么 | 怎么用 |
|---|---|---|
| A 可商用 | CC0、公有领域、CC BY、CC BY-SA、免费图库许可 | 先找这一档 |
| B 署名引用 | 版权保留，但原件方官网公开展示的图，例如馆方官网上的藏品照 | A 档没有合适的图时才用，只用于非商用的稿子，逐张署名 |
| C 不用 | 明确禁止使用的、来源不明的、带水印的付费图、CC BY-NC 或 ND 用于商用稿 | 不用 |

- **用途不主动问。** 用户自己说了“能商用”、要求可以商用，或者用途明显是商用，就只用 A 档；没提就按非商用处理，允许 B 档。

  | 非商用，可用 B 档 | 商用，只用 A 档 |
  |---|---|
  | 学校或自学的教学课件 | 收费课程、商业培训 |
  | 内部研究、内部汇报 | 收费讲座、出售的课件或模板 |
  | 个人学习、读书分享 | 营销、广告、品牌发布、招商路演 |

- **用到 B 档时只提一句。** 交付说明里写一句话，例如：“第 3、5 页两张图来自故宫官网，按署名引用使用，适合教学和内部汇报；用于收费或营销场合要换图。”同时在那几页的演讲者备注里写“仅限非商用引用”。末页致谢照常署名，不重复这个限制。没用到 B 档就不提许可风险。
- **逐件核对**：看图片所在页或接口返回的许可，不凭网站的整体印象。
- **记清来源**：每张外部图的来源页、作者、许可和档位，都写进所在页的演讲者备注；末页致谢列出全部来源。CC BY 和 BY-SA 必须署名。裁切、调色算改动，BY-SA 的图要注明改动，并按同一许可提供。
- 不用 unDraw 等禁止打包分发或嵌入应用的素材库。
