# 专业研究与咨询报告风：按需流程

用户要投资研究、行业研究、咨询建议、董事会或投委会材料，读者会逐页对照数据和来源，希望“专业、严谨、可核对”时读本文。这是一种做法，不是模板：颜色、字号和版面仍由主题与内容决定，不要照抄本文的任何具体值。

## 这种风格靠什么成立

- **结论先行**：标题直接写结论，一页只讲一个主张；读者只读标题也能跟上论证。
- **证据可核对**：每页脚注写来源与口径，数字带单位和期间。披露事实、企业目标、外部预测、自己的测算分开标注，不混在一张表里。
- **克制的颜色**：一条深色加一种强调色，只用颜色表示层级；警示（反证、风险）单独用另一种颜色，别处不用。
- **对齐比装饰重要**：同一页的文字、线、表格和图片左边缘在同一条线上，数字列右对齐，列与列之间留足间距。

## 不要做成一个模板

专业不等于每页都是“标题加一张大表”。页型按内容选：

- 主图加结论、图表加旁注、指标大数字、二维矩阵、漏斗、阶梯、流程、时间轴、证据对照、现场照片。
- 页眉、来源脚注和页码是固定件，页面主体要变。同一种骨架连续不超过两页。
- 密集页和稀疏页交替：一页密集表之后，接一页大数字或大图。
- 做完把所有页缩略图排成一排看节奏；三页以上长得一样，就换页型或合并内容。
- **反证、风险、结论提示这类固定条幅不要每页都放，位置也别固定。** 只放在真有反证的页，并换着用整行条幅、文内标签行、侧栏框；条内文字要在条里垂直居中（按行数估高，不要手填偏移）。

## 图片

研究类稿也需要真实的现场和实物：客户现场、设备形态、产线、仓库。让一半以上的论证页有一张能说明问题的图，同一张图不要出现两次。

- 可用来源：公有领域、CC0、CC BY（脚注署名）。企业新闻图带版权，只在讨论该企业时使用，并在脚注写明版权方。
- 与被研究对象无关的图写“示意”。图注和脚注要说清楚拍的是什么，不能暗示成被研究对象。

## 对齐与表格

- 原生 Table 目前不能设列宽和单元格内边距，列与列的文字会贴在一起，窄列还会单字断行。表格是核心证据时，用 Text 加细线手排：按内容给列分配宽度，左右各留 0.15in 以上，同一行单元格顶对齐，数字列右对齐，表头与首列文字的左边缘对齐。
- Text 自带约 0.1in 的左右内边距和 0.05in 的上内边距。要让文字边缘与线、图、表对齐，把文本框向外扩这些量。
- 预设 chevron 在窄长条上缺口很深，会吃掉文字。长箭头段用 polygon 自己画，缺口固定在 0.2 到 0.25in。
- 单元格里的长句主动断成两行，两行长度接近，不要留单字成行。

## 字体

中文用微软雅黑或等线，数字和西文用 Arial，都是 Office 通用字体。全稿只用标题、小标题、正文、脚注几档字号。不用书法字体。

## 检查

- `text_single_glyph_last_line`：窄列加宽，或把句子手动断成均衡的两行。
- `content_area_underused`：放大表格字号或补一张图，不靠装饰填空。
- 逐页核对来源脚注、图表编号和单位；缩略图上看，反证提示不应出现在每一页，也不应总在同一个位置。
