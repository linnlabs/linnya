# 文档卡只读详情

单张选中文档卡在75%以上近景、没有文字草稿且项目身份有效时，挂载唯一只读DOM；框选和远景继续使用位图。锁定及格式只读不影响阅读。关闭后当前选择不自动重开，重新选择可再次展开。

消费通用 `mountDocumentPreviewDetail`，Host负责当前项目复核、文档/插件状态、Markdown全文和类型owner只读组件。Canvas只负责卡片位置、近景判定、精确位图屏障及挂载取消。切卡/缩小/关闭会取消旧实例；迟到的挂载只释放自己。没有Canvas/Slides类型分支，也不创建可写文档会话。

正文编辑与详情通过Surface的唯一活DOM槽控制kernel位图隐藏；只有详情挂载成功后才替换封面，失败保留原封面并显示错误。精确光栅能力不可用时静默继续只读详情，不向用户显示提示；页面暂时隐藏不会取消详情正在等的精确图。标题双击或“打开文档”导航到正式文档，详情正文保留选字复制；内部链接遵循Host只读合同。普通滚轮滚动正文，捏合/Command滚轮和Space/中键拖动仍控制画布；关闭/Escape回焦画布。

样式包含在Canvas既有公开CSS贡献中，内容来自Host公共挂载门面，不复制Host正文实现或解析器。业务测试覆盖取消、迟到结果、权限失败、精确位图屏障与滚动分流；Native排版/交互仍需实际桌面验证。
