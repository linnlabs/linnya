# 卡片标签

卡片可以挂若干工作区标签（与文档的 #标签 同一套词汇）和一个状态角标。画布只存储、显示、筛选与查询，不赋予任何含义；词汇由用户、Agent 或其他插件在语义层定义。

- 存储：卡片字段 `tags`（标签 ID，按添加先后）与 `status`（一个标签 ID）。名称不进画布内容，改名、合并后自动显示新名称；已删除的标签不再显示，撤回删除后又会出现。
- 读取：`createCanvasCardTags` 在卡片上出现新的标签 ID、或右键菜单打开时经 `canvas:tags` 读一次工作区标签目录与 ID 对应的当前名称，交给内核画标记、交给搜索按“#名称”匹配。
- 写入：右键菜单的“标签”子菜单勾选挂上或取下（选中的卡都带着时取下，否则只给没带的卡挂上，满 12 个的跳过），“状态”子菜单设定或清除状态。锁定卡不改。都走正式用户提交，进入撤销。
- 画布不新建、改名或合并标签：工作区还没有标签时菜单不出现。Agent 用 `linnya schema add-tag` 新建后再挂到卡上。
