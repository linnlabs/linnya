# 自动排布和树状键盘

工具栏用同一 Backend arrange/cancel-arrange 合同执行树状、网格或分层排布。后台拥有计算、最终字段/尺寸/编辑保护重验和共同提交，Renderer 只同步正式序号、显示诊断并提供取消。Undo 会等待本次计算收口，避免撤到前一个无关动作。关闭表面取消仍在计算的工作。

树状键盘是当前视图的显式模式：Tab 创建子卡，Enter 创建同级卡；关闭后 Enter 恢复编辑。正文组合输入、编辑器换行及工具栏原生键盘优先。父子只来自连线 from→to，与箭头画法及分区 parentId 无关；多父时同级创建必须明确拒绝，不能取第一条关系。

新卡先走 textCreation 本地草稿；有效保存把 addText、connect 和所属连通分量排布作为一次请求交给 Backend，临时引用由后台绑定。空草稿不创建任何记录；新卡落在分区内时由统一用户提交入口归入该分区。

Tab/Enter 创建先按本地草稿的实际矩形显露正文，保留当前倍率；保存排布后再次按正式卡片位置显露，不能沿用排布前的预测位置。视野只使用同一 viewport reveal 相机规则，不提交位置变化、伪造卡片身份或向空草稿追加撤销项。
