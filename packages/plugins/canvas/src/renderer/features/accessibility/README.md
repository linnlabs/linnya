# 键盘与可读选择

默认模式Tab/Shift+Tab按画布阅读顺序逐张选择：顺序由 `shared/reading` 的
`orderCanvasCardsForReading`
唯一给出，搜索结果、读屏的“第几张”、选区引用与 Agent 投影共用它，不存隐藏顺序，拖动或排布后立即按新位置计算。规则是按版面从左上到右下按行读，与这一行里最矮者上下重叠过半的卡算同一行，行内从左到右；连线成树（唯一根、每张卡至多一个上级、无环，父子按连线 from→to）的一组卡作为一块参与排行，块内从根开始一支读完再读下一支。多上级、成环或端点在空白处的连线不算树。

没有选中时Tab选第一张、Shift+Tab选最后一张；多选时Tab从选区里阅读顺序最后一张之后继续，Shift+Tab从最前一张之前继续，结果为单选。首尾放行浏览器默认Tab，工具栏仍可通过键盘到达。树模式的Tab/Enter保留已约定的新建子节点/同级行为。

Command或Control加方向键按卡片边缘距离选：先选正对着的卡（垂直于方向的跨度有重叠），没有再选45°范围内最近的，仍相同时取阅读顺序靠前者；该方向没有卡时不消费按键。多选时以选区外框为起点。锁定卡也可阅读，普通方向键仍执行既有移动操作。

目标规则是纯函数，导航编排只冻结目标身份、等待选择/草稿保存并显露成功选中的卡。是否消费Tab在异步保存前同步决定，避免浏览器先跳焦；保存失败保留原选区时不移动视口。显露仅按需平移，不修改当前倍率，超长卡对齐卡顶。输入框、按钮与文字编辑中的原生键盘行为不被覆盖。

选择的读屏摘要按阅读顺序列出，包含类型、当前可访问文档标题或有界正文、锁定状态及“第几张/共几张”，不朗读世界坐标或内部文档身份。正文和标题仍沿用shared搜索投影，避免第二套内容解释。业务测试覆盖阅读顺序与叠放顺序无关、多选续接、正对优先的方向选择、首尾退出、只读卡、异步阻止默认跳焦、保存失败和长卡显露；成树判定与搜索同序由
`shared/reading` 测试覆盖。
