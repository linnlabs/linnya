# 键盘与可读选择

默认模式Tab/Shift+Tab按文档卡片顺序逐张选择，首尾放行浏览器默认Tab，工具栏仍可通过键盘到达。树模式的Tab/Enter保留已约定的新建子节点/同级行为。Command或Control加方向键选择对应半平面内距离最近的卡；锁定卡也可阅读，普通方向键仍执行既有移动操作。

目标规则是纯函数，导航编排只冻结目标身份、等待选择/草稿保存并显露成功选中的卡。是否消费Tab在异步保存前同步决定，避免浏览器先跳焦；保存失败保留原选区时不移动视口。显露仅按需平移，不修改当前倍率，超长卡对齐卡顶。输入框、按钮与文字编辑中的原生键盘行为不被覆盖。

选择的读屏摘要包含类型、当前可访问文档标题或有界正文、锁定状态及世界位置，不朗读内部文档身份。正文和标题仍沿用shared搜索投影，避免第二套内容解释。业务测试覆盖首尾退出、空间选择、只读卡、异步阻止默认跳焦、保存失败和长卡显露。
