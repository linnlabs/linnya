# 尚未提交的文字卡

新建文字卡先在本地形成矩形与正文草稿，不伪造持久 CanvasCardId。空正文结束直接清掉草稿，不提交、删除或调用撤销。首次有效保存一次提交 addText，以及可选来源连线；两者共享同一事务和历史组。

首次提交的命令集合由纯函数 `buildCanvasTextCreationCommands` 从草稿生成；编排只负责保存屏障、提交和将已创建卡片交给正式编辑会话，不能在命令生成过程中发送或清理草稿。

发送前与文件保存屏障也会等待首次提交。保存期间继续输入保留编辑序号，提交后交给真实卡片编辑会话继续保存；失败保留原草稿。中文组合输入结束前不提交。连线创建时，朝向来源的边中点随自动高度保持在松手位置。
