# Agent 改动组

持久组保存对话在画布上的实际字段片段，完整事实不依赖同步日志。`projectCanvasAgentGroup` 只将新增、删除及内容变化计入审阅；仅坐标、排序和预留分组变化仍能撤回，但不产生内容角标。

`changes.fields` 来自成功提交的历史片段。`outcomes.skippedWrites` 保存正式逐操作字段结果和请求编号，包含一条部分成功操作中真正跳过的字段；旧回执缺字段结果时为 null，不能从原patch或当前卡片推测。旧组没有结果事实时 `complete=false`，只说明之后已记录的跳过。重放正式回执不再次追加；全跳过的批次不更新时间上的最后正文写入。

逐卡撤回包含本组与该卡相关的连线，实际后写、外部使用和依赖保护仍由共享逆变更规则决定。撤回结果中的 applied + later_fields_preserved 是部分成功，不能显示成全部失败。

`queries.ts`是回执的只读公开入口，持久行读取与投影独立于审批、写入和历史运行态。`receipt`只读取指定画布与对话原有request-id的状态及逐项结果，不重放命令；查询输出使用VFS路径，缺失返回null，不从当前内容猜历史结果。独立CLI须显式提供项目和对话，并以SQLite只读连接执行。
