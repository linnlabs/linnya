# Canvas 事实查询

`queryCanvas` 消费一次内容快照和当前可访问的引用投影，提供全文、搜索、邻居与九宫格查询；卡片与连线都带最后修改来源（只分用户与 Agent）和本机时间。

`queryCanvasChanges` 把某提交序号之后的变化日志折成每个元素的净变化：先加后删不出现，多次修改合并字段，来源与时间取最后一次；Agent 来源只说明是否本对话，不输出对话或运行身份。最多列 200 项并保留真实总数。日志有界，范围早于保留窗口（或按时间查时最早保留的一条已在时点之后）时标为不完整并提示用 read，不能把残缺结果当全貌。已删除元素的文档引用按当前项目权限解析，不可访问的仍显示占位。文档标题来自引用 owner，不能用内部目标 ID 替代缺失信息。搜索最多返回 100 条并保留真实总数。

`checkCanvas` 与 Pixi 共用 `shared/geometry` 的真实端点、同侧排开与曲线采样，不维护第二套直线近似。固定以 100% 缩放检查交叉，端点接触不算穿越；报告标明过长和离群的启发阈值。重叠/交叉的总数准确，样本各最多 100 对，避免密集画布生成无界诊断数组。后台调用应在线程中执行，不能因纯函数同步而阻塞 App Server。

分区本来就包着自己的成员：成员完整落在所属分区里不算重叠；成员伸出分区边、分区与非成员卡、分区与分区之间、别的分区的成员压在这个分区上，照常计入。

几何检查按事实职责分开：卡片重叠/离群、正式曲线采样/长度、曲线对交叉。`checkCanvas` 只组合同一内容快照的结果；空间排序与100对有界样本不改变总计数，也不把端点接触算穿越。
