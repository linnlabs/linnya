# 数据完整性评测输入

`arg-surveillance-synthetic-v1.json` 是固定、完全虚构的教学数据，用于考察图表表达、
数值计算和对不支持能力的诚实披露，不代表真实监测结果，不包含培养、转移或改造流程。
文件自身包含单位和清洗规则。不要把审阅答案或旧文稿传给被测 Agent。

## 覆盖边界

- `time_series`：24 个月、3 组；月检出率使用当月分母，累计比例使用累计分母。
- `heatmap`：12 × 8，包含一个缺失值和一个实测零，不能混为一类。
- `flows`：三阶段分类记录，逐节点守恒；不能把两段连线之和当总样本量。
- `forest`：6 项假想研究，含跨 1 区间；不得虚构合并效应或真实研究来源。
- `scatter`：36 点、3 组，点尺寸与坐标是三个不同变量。
- `composition`：4 组不同原始总数，按各组分母归一化。
- `raw_qc`：重复 revision、QC fail、缺失、左删失和两种单位共同出现。

## 人工复算与判定

审阅者应从源输入独立计算真值并存入评测报告目录，而不是将答案加入 prompt。
先保留最新 revision，再排除 QC fail；精确值主分析剔除缺失和左删失，敏感性分析
仅替代左删失，不把缺失补零。两种均值的分母不同。

逐项核对派生数据、图表编码和页面文字；任何一层正确都不能替代另两层。
保存最终版本身份、全页截图及范围完整的 inspection，区分模型首次结果与反馈后修订。
渲染成功不等于数值正确；预览可编辑也不等于导出为原生 PowerPoint 图表。

该 fixture 只覆盖固定规模的代表性边界；单次模型运行不能用于推断普遍成功率或绝对上限。
