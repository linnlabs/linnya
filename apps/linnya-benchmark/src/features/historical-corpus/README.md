# Historical corpus preflight

这是 Benchmark 的离线材料准入检查，不是生产 Web 工具，也不是运行隔离沙箱。
`forecast-preflight --manifest FILE --output DIR`
只读取本地冻结文件，不联网、不调用模型。

Manifest 声明独占截止时间、事前要求的材料类别和候选来源。候选分为待核实与已人工核实历史版本两类；后者必须绑定原件、文本投影和历史证明的文件及 SHA-256，并记载版本身份、可得时间和核查理由。日期必须有时区。今天下载的 hash 只锁定本次字节，不能证明历史可得性。工具不能自动证明操作者提交的时间或证明真实，必须保留人工核查这个限制。

检查按资料的**可得时间**，不按数据所属月份；截止时刻本身不准入。来源身份、URL、文件路径、原件/投影/证明 hash 均须通过，缺失类别会阻止冻结。仅接受 manifest 目录内的普通文件，解析真实路径后拒绝符号链接越界。未知顶层字段（如结算答案）被 schema 拒绝；核查理由、证明和操作者元数据不会复制到作者材料中。

通过时输出
`corpus.json`，它仅包含中性来源信息与已核实的文本投影；`preflight.json`
始终说明执行隔离尚未检查。失败时不输出作者 corpus。输出目录必须是新的，不能覆盖旧的通过回执。整个目录只供后续历史 Web
adapter 使用，不应整体提供给研究 Agent。

这一步不证明当前 CLI 已能严格回测。启动模型前仍须验证根/子/深搜共用该 corpus、禁止实时网络及宿主/知识库旁路、缓存与续读不串源、恢复身份锁定，以及计算输入未使用未来数据。不得以此命令通过代替完整运行边界验收。公共测试只使用合成资料。
