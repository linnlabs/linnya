# 图题注

图片 caption 与图表 title/description 共用图下居中题注，位于图形、图例、量尺脚注和临时阅读提示之后；空值不保留占位，不生成图号。图片 alt/title 不参与显示题注。图表标题/图片题注最多 200 字，图表说明最多 1000 字，编辑器提交单行纯文本并自然折行。

题注字号由内容角色自动决定，默认比文档正文基准小一级。图片与图表遵守同一规则；AI 只提供标题／说明文字，不需要知道基础字号。文档合同不增加字号值或档位，编辑器也不提供字号设置。主题字阶调整时必须同步核对屏幕、图表图片导出与 PDF；导出构图目前独立定义尺寸，不能只修改 CSS 后就认定输出已同步。

`FigureCaptionField` 使用公共 CustomTextarea 的输入状态外观；阅读态和编辑态共享文字排版、内边距与边框占位，按实际内容自然折行，点击时不扩大。Desktop Chromium 的内容尺寸布局负责编辑态高度及容器变宽/变窄后的重排，不套用普通多行表单的最小高度或脚本测量上限。组合输入期间 Enter 和失焦不会提前提交，结束组合后处理延迟失焦。Enter/blur 提交、Esc 取消，无变化不产生事务。提交前比较整个节点的版本，Pending、历史只读或源码面板期间不能覆盖内容。NodeView 保留 Tiptap 默认 stopEvent；题注容器隔离自身按键/鼠标事件。

NodeView 拥有字段与块的映射，通过一次独立历史分组的属性事务提交，形成一步撤销；共享组件不访问文档 store。编辑期间请求虚拟化 keep-alive，图注进入初始估高，最终由真实尺寸测量校正。HTML figcaption、图表 PNG 和 PDF 均保持图下位置。

原位编辑只保留焦点描边过渡：新输入节点不能把已有悬停背景先清成透明、再淡回同一底色。背景在聚焦首帧直接到位，避免尺寸已稳定但切换仍闪动。

验证包括输入法/并发草稿测试、图片原子 Pending 与复制测试，以及真实 Electron 中的 ChartBlock/ImageBlock 提交、单步撤销、取消、只读和明暗窄屏检查。
