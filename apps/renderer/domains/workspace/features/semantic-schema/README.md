# 标签管理弹窗

从项目概览文件页“标签”筛选菜单底部的“管理标签…”打开。标签和字段整个工作区共用，弹窗标题旁写明这一点。
数据口径与写入规则由 Host 的 [`application/semantic-schema`](../../../../../../src/app-hosts/linnya/application/semantic-schema/README.md) 定义。

- 标签页：左边列表（文档数，名称相近的标“名字相近”），右边详情：改名（回车或失焦提交；名称相近时说明像谁，可“仍然改名”）、
  谁在什么时候新建、相近标签的合并入口、带的字段（“改字段”点选）、用在哪里（按项目分组的文档，当前项目的可点开；引用它的保存的筛选）、
  合并到…、删除。合并与删除先读影响范围再确认。
- 字段页：改名、类型（换类型先预览这些值能转、转不了、会变空，并给样例与文档名，确认后“转换”）、单选与多选的选项（改名、上移下移、
  删除、添加；删掉的选项有文档在用或有筛选引用时先确认）、用在哪里、删除。插件维护的字段只读。
- 最近改动：标签和字段本身的改动，新的在前，写明影响了多少文档和保存的筛选、谁做的、什么时候；每批可撤回，撤回失败写明原因。

每次写入后弹窗换回整份数据，并通知文件页重读文档与保存的筛选。弹窗里的菜单用 `--linnya-ui-layer-portal-menu` 层，盖在弹窗之上。

- `infrastructure/`：Backend 请求，按共享合同解析。
- `orchestration/`：弹窗数据与写入状态。
- `functions/`：摘要、来源与计数文案，查找。
- `ui/`：弹窗、标签页、字段页、最近改动、用在哪里、合并目标菜单。样式在 `styles/features/semantic-schema/`。
