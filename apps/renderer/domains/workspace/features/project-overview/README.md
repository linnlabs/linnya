# 项目概览

项目级只读文件表：跨文件夹展示可见文档，支持名称和正文搜索、类型/时间/位置筛选、排序及本机列偏好。
资源库内部文档不在表中。数据口径由 Host 的 `application/project-overview` 定义。

- `definitions/`：行模型、筛选与列布局合同。列布局版本为 1，所有项目共用本机偏好。
- `functions/`：数据转换、筛选、排序、展示文案、列布局变换和刷新范围判断。
- `orchestration/`：读取快照、合并工作区变更、正文搜索。同项目读取串行执行，期间的新事件留给下一轮；切换项目后旧响应失效。正文搜索随查询或文档快照变化重新执行，失败时明确提示仅按名称显示结果。
- `store/`：知识库弹窗状态和持久化列布局；不存项目文档的第二份持久化副本。
- `ui/`：虚拟表、筛选与列设置。名称列固定，其他列可隐藏、拖动排序、调宽；列设置也支持 Alt+↑/↓ 排序。

页面由 `app/pages/ProjectOverviewPage` 装配。文档类型、图标及插件名来自注册表；打开文件前必须将节点类型转换为注册表中的 `activeDocumentType`，不能把数据库类型直接传给导航。插件不可用时沿用现有说明。跨领域的文件/对话导航与知识库关联由 app 层处理。

正文搜索复用 VFS 行索引，最多返回 500 处命中，达到上限时提示；搜索失败不展示上一次查询的结果。根目录筛选只含根目录文件，其他文件夹筛选包含其子文件夹。

验收入口：相关 Vitest 测试，以及 `scripts/e2e/conversation-navigation/run-electron-conversation-navigation-e2e.mjs` 的 `project-overview` 场景（通过 `LINNYA_CONVERSATION_E2E_SCENARIO` 选择）。真实 Desktop 场景使用隔离临时数据库，验证导航、筛选、列设置、知识库关联、变更刷新及大量文档的虚拟渲染。

当前边界：插件用户编辑未完整进入账本时只展示修改时间；CLI 经运行入口写入的来源目前显示为 Linnya AI。这两项来源精度由各写入入口后续补齐，不由本视图推测。
