# Shared Hover Preview

`shared/hover-preview/` 只承接“悬停后弹出预览浮层”的时序规则，编辑器正文里的文档引用和对话输入框里的引用标签共用它，两处的手感因此一致。

## 规则

- 指针停留 150ms 开始准备：调用方此时取数据，并在**还不可见**的浮层里把首屏排好。
- 停留 400ms 到露出时间。内容已排好就立刻露出；没排好最多再等 150ms，仍没好就露出调用方的占位。这样读过的文档带着内容一次出现，不会先闪一个空面板或占位。
- 露出前指针离开，立即取消（在途读取随之中止）；露出后离开，200ms 后关闭，期间指针进入浮层则保留。
- 键盘聚焦与点击不等停留时间，其余规则相同。

## 边界

- 共享层只有计时与先后顺序，不创建 DOM、不定位、不读数据。
- 调用方负责：准备阶段让浮层不可见且不接收指针；内容排好时调用 `ready()`；在自己的销毁路径里调用 `close()`。
- 时长是产品手感的一部分，改动要同时在两个入口实测。
